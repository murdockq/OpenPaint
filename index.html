OpenPaint

OpenPaint keeps the classic look and feel of paint, but will never add AI features, instead modernizing with image tabs and cross-platform support.

Feature highlights

  • Cross-platform packaged releases for Windows, macOS, and Linux
  • Tabbed multi-document editing with split tab groups for side-by-side work
  • Rectangular and free-form selection tools with floating selection support
  • Pencil, brush, airbrush, line, curve, polygon, text, fill, magnifier, eyedropper, and eraser tools
  • Rectangle, rounded rectangle, and ellipse shape tools with adjustable line widths
  • Resize, scale, flip, 90-degree rotate, and arbitrary-angle rotate operations
  • Histogram view, zoom controls, undo/redo, and broad bitmap format support

Supported formats

OpenPaint currently supports BMP, PNG, JPEG, GIF, WEBP, PCX, PNM, TIF, XPM, ICO, and CUR image files.

Requirements

  • Windows builds from source use vcpkg for wxWidgets.
  • Linux builds need libwxgtk3.2-dev.
  • macOS builds need wxwidgets from Homebrew.

Build from source

OpenPaint uses CMake and wxWidgets.

cmake -B build
cmake --build build --config Release

To build and run the test suite:

cmake -B build -DOPENPAINT_BUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
